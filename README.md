# Circuito Verde

> **Reciclando ideias, reprogramando o futuro.**

O **Circuito Verde** é uma iniciativa da **Profª Maristela** que conecta tecnologia, educação, inclusão e sustentabilidade. Este site apresenta a proposta do projeto, seus temas de aprendizagem e uma seleção de criações desenvolvidas com cultura Maker e reaproveitamento de materiais.

## O que você encontra aqui

- a missão e os valores do Circuito Verde;
- tecnologias e recursos usados nos projetos;
- galeria de criações com sucata eletrônica, Arduino e componentes reutilizados;
- página de projetos e referências visuais;
- informações sobre educação tecnológica, STEAM e inclusão digital.

## Um site simples de publicar

O projeto funciona como um site estático: não usa Flask, Python em runtime, banco de dados ou autenticação. Os links, estilos, imagens e scripts são arquivos locais, prontos para serem publicados em GitHub Pages ou qualquer hospedagem de arquivos estáticos.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Font Awesome, Google Fonts e integrações visuais externas

## Estrutura

```text
circuitoverde-1/
├── index.html        # página inicial
├── galeria.html      # galeria de imagens
├── projetos.html     # carrossel de projetos
├── README.md
└── static/
	├── css/          # folhas de estilo
	├── favicons/     # manifestos e ícones
	└── img/          # imagens e logos
```

## Como abrir

Abra o arquivo `index.html` diretamente no navegador. A navegação entre a página inicial, a galeria e os projetos usa links simples relativos, portanto o site também funciona localmente e em subpastas de hospedagem.

## Publicar no GitHub Pages

1. envie os arquivos para um repositório no GitHub;
2. abra **Settings > Pages**;
3. em **Build and deployment**, selecione a branch principal e a pasta `/ (root)`;
4. salve e aguarde o endereço ser disponibilizado.
